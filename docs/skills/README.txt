实验设计资料

本目录随 LocalGaze Windows 便携包提供，包含完整的 localgaze-study-config 技能、实验设计填写模板、配置校验脚本、参考说明和示例。

LocalGaze 本身不需要安装此技能。若要在 Codex 中使用，可将 localgaze-study-config 文件夹复制到你自己的技能目录，再从技能选择器调用。目录位置由你的 Codex 设置决定，本资料不使用固定机器路径。

请记录研究问题、主要结局、实验单位、设备、数据格式、单位、来源、状态和风险。状态为 known、proposed、missing 或 not_applicable。缺少会影响正确执行或解释的信息时，先停在草案。

配置结构检查只能证明 JSON 可加载，不能证明方法科学、数据质量、GUI 执行或统计结果正确。LocalGaze 没有通用推断统计引擎；每项研究须另备符合设计的统计计划与脚本。软件自检和候选指标不能作为真实眼动精度证据。

本资料不启动采集或分析。保留原始数据，所有生成结果写入新的空目录。
