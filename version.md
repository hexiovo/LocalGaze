## S01 changes landed so far

- Added a lightweight frame data contract with monotonic receipt timestamps, session-relative elapsed time, frame-ID duplicate rejection, sample status, and raw/derived field provenance.
- Added an independently callable 2-D iris landmark-ring proxy using centers 473/468, four surrounding points per eye, pixel coordinates, and the outer eye-corner span. The proxy is explicitly not a pupil measurement.
- Added pixel-scaled EAR and an open-eye baseline warm-up with close/open hysteresis; invalid EAR samples keep the last valid hysteresis state without updating the baseline. Warm-up seeds from the highest 30% of EAR values observed in its initial sample window, so it depends on representative open-eye samples and does not promise reliable all-closed startup. Added an iris-formula version switch and explicit legacy output path.
- Added versioned feature metadata, calibration frame ledgers with duplicate rejection, target/visit-balanced Ridge weights, fit and visit-holdout residual metadata, and explicit errors for unsupported weighted estimators.
- Added bounded latest-frame capture records with local and monotonic receipt/processing times, frame statuses and reasons, dropped-frame counts, English and Chinese iris proxy fields, legacy TSV columns, and exclusive same-session TXT creation. Receipt time is the completion of a successful OpenCV read, not a sensor exposure timestamp. `processing_duration_ns` covers the later feature/prediction processing interval; it excludes capture-thread pixel hashing and is not total pipeline latency. The caller owns the matching XLSX and manifest.
- Added a nullable `duplicate_image` capture field derived from pixel signatures of consecutive successful reads. Receipt timestamps are recorded immediately after a successful read and before hashing. Repeated pixels remain recorded and do not affect sample acceptance; identical pixels do not establish a repeated exposure. The manifest documents the field's source and that null means NA.
- Versioned gaze models now require the canonical feature schema and supported scaling description at load and prediction time; scaler and optional variable-scaling dimensions are checked against the schema width. Eye-state hysteresis now retains the last valid open/closed state across invalid EAR samples without updating the open baseline.
