LocalGaze 快速开始
程序版本：2026.10.31.0
适用系统：Windows 10/11，64 位

便携版

1. 从 GitHub Releases 下载 LocalGaze-2026.10.31.0.zip，并解压到你有写入权限的文件夹。
2. 保留同一目录中的 LocalGazeWorker.exe、ROIDrawing.exe、_internal、docs 和 third_party。
3. 双击 LocalGaze.exe。便携包使用随包运行环境，不会自动下载或安装 Python。
4. 打开“环境检查”查看运行依赖。检查通过不代表摄像头、采集精度或每台电脑上的显示行为已验证。

开始使用

1. 在“会话与采集”填写会话 ID，按需要选择模型和输出位置。校准与正式采集使用的设置应符合你的设备和研究方案。
2. 需要标注区域时打开“ROI 绘制”，先让目标图片或视频显示在要标注的屏幕上，再选择屏幕和形状。保存后的 ROI 工作簿可在分析时选择。
3. 在“预处理与 QC”选择眼动文件或映射表，设置时间单位及界面提供的预处理参数。原始输入保留；结果写入所选的新输出位置。完成后检查 QC 报告、文件清单和任务状态。
4. 在“分析导出”选择文件、指标、ROI 和结果位置。LocalGaze 提供描述性指标、事件候选和导出，不是通用推断统计引擎。
5. 工作区上方的“保存配置”和“加载配置”用于保存、恢复界面设置。加载只填入控件，不会启动任务；配置里的文件路径仍需你检查。

实验设计资料

便携包的 docs/skills 目录包含实验设计填写模板和完整技能说明。它用于整理参数、数据转换和统计执行计划，不会代替研究设计判断，也不会启动采集或分析。使用时保留原始数据，先解决标为 missing 的关键信息，并将结果写入新的空目录。

限制

- 默认参数是工程设置，不是适用于所有设备或研究的验证阈值。
- 软件自检和合成数据检查不能证明真实摄像头链路或独立眼动精度。
- I-VT 眼跳、注视、眨眼和运动结果属于工程候选，不等于生理真值或独立验证结果。
- ROI 分析要求 gaze 与 ROI 使用同一且已核实的坐标参考。不要仅凭预览看起来合理就缩放 ROI。
- 多显示器 DPI 行为及特定电脑上的效果尚未全部验证。正式采集前应在目标设备上完成适当的检查和试运行。

源码启动与许可

从源码运行时，Windows 10/11 x64 可用 Python 3.10 或 3.12；首次启动会在项目目录创建 .venv 并安装 requirements.txt。构建便携包建议使用 Python 3.12.14 或更新的 3.12 维护版本，构建依赖安装到项目 .venv。第三方来源与许可见 THIRD_PARTY_NOTICES.md 和 third_party/licenses。
